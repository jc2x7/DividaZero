Política de Privacidade

🔒 Este app é 100% offline — não coletamos, armazenamos nem compartilhamos nenhum dado seu em servidores.

📄 Introdução

Esta Política de Privacidade descreve como o aplicativo Divida Zero ("nós", "nosso", "o App") trata as informações dos usuários ("você").

Ao instalar e usar o Divida Zero, você concorda com os termos descritos nesta política. Se não concordar com qualquer parte, por favor, não utilize o App.

Desenvolvedor: Divida Zero — Aplicativo de Finanças Pessoais
Contato: consulte a seção de contato ao final desta página.

🚫 Dados que NÃO coletamos

O Divida Zero foi projetado com privacidade por padrão. O App não coleta absolutamente nenhum dado pessoal. Especificamente:

  • Não coletamos nome, e-mail, telefone ou qualquer dado de identificação pessoal
  • Não coletamos dados financeiros para nossos servidores
  • Não rastreamos localização geográfica
  • Não acessamos contatos, câmera, microfone ou galeria de fotos
  • Não coletamos dados de uso, comportamento ou analytics
  • Não coletamos informações do dispositivo ou identificadores únicos
  • Não exibimos anúncios e não compartilhamos dados com redes de publicidade
  • Não enviamos dados para servidores de terceiros

📱 Onde seus dados ficam armazenados

Todos os dados inseridos no Divida Zero (valores de empréstimos, despesas, salário, etc.) são armazenados exclusivamente no seu próprio dispositivo, em um banco de dados local (SQLite) que nenhum outro app ou servidor pode acessar.

Consequências importantes:

  • Se você desinstalar o App, todos os dados são apagados permanentemente
  • Se você formatar o celular sem fazer backup, os dados são perdidos
  • Nós não temos acesso aos seus dados e não conseguimos recuperá-los
  • Seus dados nunca saem do seu celular, a menos que você mesmo os exporte

🔑 Permissões utilizadas pelo App

O Divida Zero utiliza apenas as permissões estritamente necessárias para seu funcionamento:

Permissão Motivo Dados coletados?
USE_BIOMETRIC
USE_FINGERPRINT		 Desbloquear o app com impressão digital ou Face ID. A autenticação ocorre localmente no dispositivo. Não
RECEIVE_BOOT_COMPLETED Reativar notificações de lembretes de vencimento após reiniciar o celular. Não
VIBRATE Vibrar ao exibir notificações locais de vencimento. Não

O App não solicita permissão de internet, portanto é tecnicamente impossível que qualquer dado seja transmitido pela rede.

🔔 Notificações locais

O Divida Zero pode enviar notificações locais para lembrar sobre vencimentos de empréstimos. Essas notificações são geradas e exibidas inteiramente no seu dispositivo, sem nenhuma conexão a servidores externos.

Você pode desativar essas notificações a qualquer momento nas configurações do seu Android.

☁️ Função de Backup e Exportação

O App oferece a opção de exportar seus dados em formato JSON para fins de backup pessoal. Ao usar essa função, você pode compartilhar o arquivo via Google Drive, e-mail ou outros serviços de sua escolha.

Importante: O destino dos dados exportados é de sua inteira responsabilidade. Nós não recebemos, armazenamos nem temos acesso aos dados exportados. As políticas de privacidade dos serviços onde você salvar o backup (Google Drive, etc.) se aplicam separadamente.

🤝 Serviços de terceiros

O App é construído com o framework Expo / React Native. Durante o uso normal, o App não se comunica com nenhum servidor externo.

O Expo SDK pode, durante o processo de build ou atualização do próprio App, fazer comunicações com servidores da Expo Inc., mas isso ocorre fora do contexto de uso do usuário final e não envolve dados pessoais dos usuários.

  • Sem Google Analytics ou Firebase
  • Sem Facebook SDK ou outros SDKs de rastreamento
  • Sem serviços de crash reporting com dados de usuário
  • Sem serviços de publicidade

👶 Privacidade de menores

O Divida Zero não é direcionado a crianças menores de 13 anos. Como o App não coleta nenhum dado pessoal de nenhum usuário, não há coleta intencional ou não-intencional de dados de menores.

🛡️ Segurança dos dados

Como todos os dados ficam armazenados localmente no seu dispositivo, a segurança depende principalmente das proteções nativas do Android (criptografia do sistema de arquivos, bloqueio de tela, etc.).

O Divida Zero oferece adicionalmente a opção de proteger o acesso ao App com biometria (impressão digital ou reconhecimento facial), processada localmente pelo sistema operacional.

✏️ Alterações nesta política

Podemos atualizar esta Política de Privacidade ocasionalmente. Caso haja mudanças significativas, notificaremos através de uma atualização do App na Google Play Store.

A data de "Última atualização" no topo desta página indica quando a política foi revisada pela última vez. Recomendamos verificar esta página periodicamente.

⚖️ Seus direitos (LGPD)

De acordo com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento de dados pessoais (resposta: não há tratamento)
  • Acessar seus dados (todos estão no seu próprio dispositivo)
  • Solicitar a exclusão dos dados (basta desinstalar o App)
  • Revogar o consentimento (basta desinstalar o App)
  • Obter informações sobre o compartilhamento de dados (não há compartilhamento)

Como o App não processa dados pessoais em nossos sistemas, a maioria dos direitos da LGPD é exercida diretamente por você no seu próprio dispositivo.
