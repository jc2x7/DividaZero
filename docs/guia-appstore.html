7

Gerar e enviar o Build Técnico

Opção A – EAS Build (Expo, sem Mac):

  • eas build --platform ios --profile production
  • Após o build: eas submit --platform ios
  • O build é enviado automaticamente ao App Store Connect

Opção B – Xcode (Mac):

  • Abra o projeto no Xcode: npx expo run:ios
  • Menu Product → Archive
  • No Organizer: clique em Distribute App → App Store Connect
  • Siga o assistente e clique em Upload
Após o upload, aguarde de 5 a 30 minutos para o build aparecer no App Store Connect.
8

Vincular o Build à versão

  • No App Store Connect, vá em TestFlight e confirme que o build apareceu
  • Volte para App Store → Versão 1.0.0
  • Role até Build e clique em + Selecionar um Build
  • Escolha o build enviado
9

Enviar para revisão

  • Revise todos os campos — o botão Enviar para revisão fica ativo quando tudo estiver preenchido
  • Responda as perguntas finais:
    • O app usa o sistema de publicidade da Apple (IDFA)? Não
    • O app está criptografado? Não (a menos que use https customizado)
  • Clique em Enviar para revisão
  • Prazo de revisão: geralmente 24 a 48 horas
